# arjunkarpur.github.io

Personal site, built by GitHub Pages with Jekyll.

## Update content

- Papers: `_data/publications.yml`.
- News: `_data/news.yml`. Awards: `_data/awards.yml`. Empty lists hide
  their section.
- Bio: `index.html`. Links and photo: `_config.yml`.

## Preview locally

```bash
bundle config set --local path vendor/bundle
bundle install
bundle exec jekyll serve
```
